= Field Sourced Content (FSC) ガイド
:navtitle: はじめに

== このガイドについて

このガイドは、**Field Sourced Content (FSC)** を使ってデモ環境やハンズオンラボを構築する方法を、実践的なハンズオン形式で学ぶためのものです。

FSC の基本的な仕組みを理解し、テンプレートからデモ環境を作り上げるまでの一連の流れを体験できます。

== 対象者

* デモ環境やハンズオンラボを作成したいフィールドエンジニア
* FSC を使ったコンテンツ開発を引き継ぐメンバー
* Red Hat Demo Platform (RHDP) 上でワークショップを提供したいチーム

== 前提知識

* OpenShift / Kubernetes の基本操作
* Git の基本操作（clone, commit, push）
* YAML の読み書き
* Helm チャートの基本概念（任意）
