= デモ環境の構築
:navtitle: デモ環境の構築

== 学習目標

* 新しいコンポーネント（PostgreSQL Cluster）を作成し、ArgoCD に登録できる
* 既存コンポーネント（hello-world）を改修して、動的変数を表示するデモアプリにできる
* Route、ConfigMap を使ったブラウザアクセス可能なアプリを構成できる

== 全体像

このエクササイズで、以下の3つのコンポーネントが連携するデモ環境を構築します:

[source]
----
[Operator]  CNPG Operator（OLM 経由でインストール）
     ↓ 管理
[PostgreSQL]  CNPG Cluster CR → PostgreSQL インスタンスを自動作成
     ↓ 接続情報を表示
[デモアプリ]  hello-world 改修 → 動的変数 + DB 情報を表示する Web ページ
----

NOTE: 以降の作業はすべて `examples/helm/` ディレクトリ内で行います。

== エクササイズ 1: PostgreSQL Cluster コンポーネントの作成

CNPG Operator が管理する PostgreSQL Cluster を定義するコンポーネントを新規作成します。

=== 手順

. コンポーネントのディレクトリを作成します:
+
[source,bash,role="execute"]
----
mkdir -p components/postgres-cluster/templates
----

. `Chart.yaml` を作成します:
+
[source,bash,role="execute"]
----
cat > components/postgres-cluster/Chart.yaml << 'EOF'
apiVersion: v2
name: postgres-cluster
description: CloudNativePG PostgreSQL Cluster
type: application
version: 0.1.0
EOF
----

. `values.yaml` を作成します:
+
[source,bash,role="execute"]
----
cat > components/postgres-cluster/values.yaml << 'EOF'
postgresCluster:
  enabled: false
  name: my-postgres
  namespace: database
  instances: 1
  storageSize: 5Gi
  database: app
  owner: app
  resources:
    requests:
      memory: "512Mi"
      cpu: "250m"
    limits:
      memory: "1Gi"
      cpu: "500m"
EOF
----

. Cluster CR テンプレートを作成します:
+
[source,bash,role="execute"]
----
cat > components/postgres-cluster/templates/cluster.yaml << 'ENDOFFILE'
{{- if .Values.postgresCluster.enabled }}
---
apiVersion: v1
kind: Namespace
metadata:
  name: {{ .Values.postgresCluster.namespace }}
---
apiVersion: postgresql.cnpg.io/v1
kind: Cluster
metadata:
  name: {{ .Values.postgresCluster.name }}
  namespace: {{ .Values.postgresCluster.namespace }}
  annotations:
    argocd.argoproj.io/sync-wave: "2"
spec:
  instances: {{ .Values.postgresCluster.instances }}
  storage:
    size: {{ .Values.postgresCluster.storageSize }}
  resources:
    requests:
      memory: {{ .Values.postgresCluster.resources.requests.memory | quote }}
      cpu: {{ .Values.postgresCluster.resources.requests.cpu | quote }}
    limits:
      memory: {{ .Values.postgresCluster.resources.limits.memory | quote }}
      cpu: {{ .Values.postgresCluster.resources.limits.cpu | quote }}
  bootstrap:
    initdb:
      database: {{ .Values.postgresCluster.database }}
      owner: {{ .Values.postgresCluster.owner }}
  postgresql:
    parameters:
      max_connections: "100"
      shared_buffers: "128MB"
{{- end }}
ENDOFFILE
----
+
ポイント:
+
* `sync-wave: "2"` — Operator（Wave 0）が先にインストールされてから CR を作成
* `bootstrap.initdb` — 初期データベースとオーナーを自動作成
* すべてのパラメータが `values.yaml` から注入される

== エクササイズ 2: PostgreSQL Cluster を ArgoCD に登録する

新しいコンポーネントを ArgoCD が認識するように、`templates/applications.yaml` に Application 定義を追加します。

=== 手順

. `templates/applications.yaml` を開きます:
+
[source,bash,role="execute"]
----
vi templates/applications.yaml
----

. ファイルの末尾（最後の `+{{- end }}+` の後）に以下を追加します:
+
[source,yaml]
----

{{- if .Values.components.postgresCluster.enabled }}
---
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: {{ .Release.Name }}-postgres-cluster
  namespace: {{ .Values.argocd.namespace }}
  labels:
    demo.redhat.com/application: "field-content"
  finalizers:
    - resources-finalizer.argocd.argoproj.io
spec:
  project: {{ .Values.argocd.project }}
  source:
    repoURL: {{ .Values.gitops.repoUrl }}
    targetRevision: {{ .Values.gitops.revision }}
    path: {{ .Values.gitops.basePath }}/components/postgres-cluster
    helm:
      valuesObject:
        postgresCluster:
          enabled: {{ .Values.components.postgresCluster.enabled }}
          name: {{ .Values.components.postgresCluster.name }}
          namespace: {{ .Values.components.postgresCluster.namespace }}
          instances: {{ .Values.components.postgresCluster.instances }}
          storageSize: {{ .Values.components.postgresCluster.storageSize | quote }}
          database: {{ .Values.components.postgresCluster.database }}
          owner: {{ .Values.components.postgresCluster.owner }}
          resources:
            requests:
              memory: {{ .Values.components.postgresCluster.resources.requests.memory | quote }}
              cpu: {{ .Values.components.postgresCluster.resources.requests.cpu | quote }}
            limits:
              memory: {{ .Values.components.postgresCluster.resources.limits.memory | quote }}
              cpu: {{ .Values.components.postgresCluster.resources.limits.cpu | quote }}
  destination:
    server: https://kubernetes.default.svc
    namespace: {{ .Values.components.postgresCluster.namespace }}
  syncPolicy:
    automated:
      prune: true
      selfHeal: true
    syncOptions:
      - CreateNamespace=true
{{- end }}
----

. 親 `values.yaml` に PostgreSQL Cluster の設定を追加します:
+
[source,bash,role="execute"]
----
vi values.yaml
----
+
`components:` セクション内（`showroom:` ブロックの後など）に以下を追加します:
+
[source,yaml]
----
  # --- PostgreSQL Cluster (CNPG) ---
  postgresCluster:
    enabled: true
    name: demo-postgres
    namespace: database
    instances: 1
    storageSize: 5Gi
    database: app
    owner: app
    resources:
      requests:
        memory: "512Mi"
        cpu: "250m"
      limits:
        memory: "1Gi"
        cpu: "500m"
----

== エクササイズ 3: hello-world に Route を追加する

現在の hello-world には Route がなく、ブラウザからアクセスできません。Route テンプレートを追加します。

=== 手順

. Route テンプレートを作成します:
+
[source,bash,role="execute"]
----
cat > components/hello-world/templates/route.yaml << 'ENDOFFILE'
{{- if .Values.demo.enabled }}
---
apiVersion: route.openshift.io/v1
kind: Route
metadata:
  name: {{ .Values.demo.appName }}
  namespace: {{ .Values.demo.namespace }}
  labels:
    app: {{ .Values.demo.appName }}
spec:
  to:
    kind: Service
    name: {{ .Values.demo.appName }}
  port:
    targetPort: 8080
  tls:
    termination: edge
    insecureEdgeTerminationPolicy: Redirect
{{- end }}
ENDOFFILE
----

== エクササイズ 5: Deployment を修正して HTML ページをマウントする

ConfigMap の HTML を httpd のドキュメントルートにマウントします。

=== 手順

. `components/hello-world/templates/deployment.yaml` を開きます:
+
[source,bash,role="execute"]
----
vi components/hello-world/templates/deployment.yaml
----

. `containers` セクションに `volumeMounts` を追加し、`spec` に `volumes` を追加します:
+
変更後の全体像:
+
[source,yaml]
----
{{- if .Values.demo.enabled }}
---
apiVersion: apps/v1
kind: Deployment
metadata:
  name: {{ .Values.demo.appName }}
  namespace: {{ .Values.demo.namespace }}
  labels:
    app: {{ .Values.demo.appName }}
spec:
  replicas: {{ .Values.demo.replicas }}
  selector:
    matchLabels:
      app: {{ .Values.demo.appName }}
  template:
    metadata:
      labels:
        app: {{ .Values.demo.appName }}
    spec:
      containers:
        - name: httpd
          image: {{ .Values.demo.image }}
          ports:
            - containerPort: 8080
          volumeMounts:
            - name: html-content
              mountPath: /var/www/html
              readOnly: true
          resources:
            limits:
              memory: "128Mi"
              cpu: "100m"
            requests:
              memory: "64Mi"
              cpu: "50m"
      volumes:
        - name: html-content
          configMap:
            name: {{ .Values.demo.appName }}-html
{{- end }}
----
+
追加した部分:
+
* `volumeMounts` — ConfigMap をコンテナの `/var/www/html` にマウント
* `volumes` — ConfigMap `hello-world-html` をボリュームとして定義

== エクササイズ 6: 親 values.yaml にカスタムパラメータを追加する

hello-world に追加したパラメータ（タイトル、メッセージ、テーマカラー、PostgreSQL 情報）を親 `values.yaml` に定義し、`applications.yaml` 経由で渡します。

=== 手順

. 親 `values.yaml` の `components.helloWorld` セクションを以下のように変更します:
+
[source,bash,role="execute"]
----
vi values.yaml
----
+
[source,yaml]
----
  helloWorld:
    enabled: true
    namespace: demo-app
    appName: hello-world
    replicas: 1
    image: registry.redhat.io/ubi8/httpd-24:latest
    demo:
      title: "CNPG デモアプリ"
      message: "このメッセージは values.yaml で自由に変更できます。Git push すると ArgoCD が自動反映します。"
      themeColor: "#EE0000"
    postgres:
      name: demo-postgres
      namespace: database
      database: app
    userInfo:
      enabled: true
      title: "CNPG Demo"
      instructions: "CNPG Operator で PostgreSQL を自動デプロイするデモです。"
----

. `gitops.repoUrl` を自分のリポジトリ URL に変更します:
+
[source,yaml]
----
gitops:
  repoUrl: "https://github.com/<自分のアカウント>/my-cnpg-demo.git"
  revision: "main"
  basePath: "examples/helm"
----

. `templates/applications.yaml` の hello-world セクション `valuesObject` に、新しいパラメータを追加します:
+
[source,bash,role="execute"]
----
vi templates/applications.yaml
----
+
hello-world の `valuesObject` を以下のように拡張します（`demo:` ブロックに追加、`deployer:` ブロックに `apiUrl` を追加）:
+
[source,yaml]
----
    helm:
      valuesObject:
        demo:
          enabled: {{ .Values.components.helloWorld.enabled }}
          namespace: {{ .Values.components.helloWorld.namespace }}
          appName: {{ .Values.components.helloWorld.appName }}
          replicas: {{ .Values.components.helloWorld.replicas }}
          image: {{ .Values.components.helloWorld.image }}
          title: {{ .Values.components.helloWorld.demo.title | quote }}
          message: {{ .Values.components.helloWorld.demo.message | quote }}
          themeColor: {{ .Values.components.helloWorld.demo.themeColor | quote }}
          postgres:
            name: {{ .Values.components.postgresCluster.name | quote }}
            namespace: {{ .Values.components.postgresCluster.namespace | quote }}
            database: {{ .Values.components.postgresCluster.database | quote }}
        userInfo:
          enabled: {{ .Values.components.helloWorld.userInfo.enabled }}
          title: {{ .Values.components.helloWorld.userInfo.title | quote }}
          instructions: {{ .Values.components.helloWorld.userInfo.instructions | quote }}
        deployer:
          domain: {{ .Values.deployer.domain | quote }}
          apiUrl: {{ .Values.deployer.apiUrl | quote }}
        showroom:
          enabled: {{ .Values.components.showroom.enabled }}
          namespace: {{ .Values.components.showroom.namespace }}
        operator:
          name: {{ .Values.components.operator.name }}
----

* **新規コンポーネント作成**: ディレクトリ + Chart.yaml + values.yaml + テンプレート
* **ArgoCD への登録**: `applications.yaml` に Application 定義を追加し、`values.yaml` と橋渡し
